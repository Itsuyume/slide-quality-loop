# Slide Quality Loop

HTML로 만든 발표 화면의 결함 검사, 익명 비교, 채택 결정을 분리합니다.
미감 점수의 합으로 내용 누락이나 잘못된 관계를 상쇄하지 않습니다.

## 경계와 단일 출처

- `src/domain`: 입력 스키마, 결함 검사, 비교 판정. 파일·네트워크 접근 없음.
- `src/application`: 비교 패킷과 보정 통계. domain에만 의존.
- `src/adapters`: 기존 HTML 렌더러의 스냅샷과 평가 응답을 읽는 경계.
- `src/cli.ts`: 파일 입출력과 종료 코드. 원본 HTML/Figma/PPT를 수정하지 않음.
- 내용 계약과 사용자 피드백은 실행 폴더에 둡니다. 공개 저장소에는 실제 발표 자료, 개인 경로, 인증정보를 넣지 않습니다.
- 렌더링은 기존 제작 도구를 재사용합니다. 이 패키지는 PPT를 생성하지 않습니다.

## 검증

```sh
npm ci
npm run check
```

Node 22 이상. TypeScript strict, 레이어 의존 방향, 순환 의존성, 함수 크기·복잡도 검사를 적용합니다.
CLI 사용법과 판정 규칙은 구현된 명령의 도움말 및 `PROTOCOL.md`에 있습니다.

## 범위

필수조건을 통과해도 미감 합격이 아닙니다. 위치를 바꾼 두 번의 비교, 화면에 근거한 지적,
내용 읽기 확인이 필요합니다. 작성 모델과 같은 대화에서 한 평가는 독립 검수로 인정하지 않습니다.
사람이 승인한 긍정 사례가 없으면 취향 보정 완료나 사용자 승인을 주장하지 않습니다.
평가 누락, 파일 불일치, 상반된 판정은 자동 합격이 아니라 보류입니다.
